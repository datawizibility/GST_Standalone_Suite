  Double-click  GST_Audit_Suite.exe

WHAT IS INCLUDED IN THIS SUITE:
------------------------------------------------------------------------
1. Purchase Reconciliation (GSTR-2B vs ERP Books)
   - 4-Pass Matching: Exact Match, Value Difference, Fuzzy Invoice No Match,
     Missing in 2B, and Missing in Books.
   - Official Portal Excel (.xlsx) Ingestion: B2B, B2BA, B2B-CDNR, B2B-CDNRA.
   - B2BA Amendment Replacement: Prevents false mismatch flags when suppliers
     amend previous invoice numbers or values.
   - Multi-Month Append: Combine any number of monthly files at once.
   - Dynamic Books Excel Mapping: Accepts exports from Tally, Busy, SAP, Zoho.
   - Vendor Risk Engine (0-100 Score & RAG Matrix): Highlights high-risk
     vendors and quantifies exact ₹ ITC at Risk under CGST Section 16(2)(aa).
   - 1-Click CFO/CA-Ready Multi-Tab Excel Workbook (with formula-first sums).

2. GSTR-3B PDF Data Extractor (Month-over-Month Consolidated)
   - Extracts Table 3.1 (Outward & RCM), Table 4 (Eligible ITC), Table 6.1 (Cash Paid),
     and ARN status across any number of monthly return PDF copies.

3. GSTR-1 / 1A PDF Data Extractor (Month-over-Month Consolidated)
   - Extracts Table 4 (B2B), 5 (B2CL), 7 (B2CS), 8 (Nil/Exempt), 9B (CDNR), and Total
     Liability across any number of monthly return PDF copies.

4. Statutory DRC-01B & DRC-01C Exposure Watchdogs
   - Automated monitoring for Rule 88C (GSTR-1 vs 3B liability gap) and Rule 88D
     (GSTR-2B vs 3B ITC excess claim gap) to prevent surprise tax notices.
